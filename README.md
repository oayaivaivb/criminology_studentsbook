# КРИМИНОЛОГИЯ (общая часть)

Веб-приложение — электронный учебник по дисциплине «Криминология (общая часть)» для курсантов, слушателей и преподавателей Московского университета МВД России имени В.Я. Кикотя.

## 📖 О проекте

Учебник содержит материалы общей части криминологии: понятие и предмет науки, преступность и её характеристики, детерминанты, личность преступника, механизм индивидуального преступного поведения, виктимологию, предупреждение преступлений, прогнозирование и планирование, а также организацию криминологических исследований.

Сайт включает:
- аннотацию, введение и заключение;
- 9 глав с параграфами;
- глоссарий;
- библиографический список;
- встроенные PDF-документы и видеофайлы;
- адаптивный интерфейс для ПК, планшетов и телефонов.

## 🚀 Установка и запуск локально

1. Клонировать репозиторий:
```bash
git clone https://github.com/oayaivaivb/criminology_studentsbook.git
cd criminology_studentsbook
```

2. Создать и активировать виртуальное окружение:
```bash
python -m venv venv
venv\Scripts\activate      # Windows
source venv/bin/activate   # Linux/macOS
```

3. Установить зависимости:
```bash
pip install -r requirements.txt
```

4. Применить миграции:
```bash
python manage.py migrate
```

5. Запустить сервер разработки:
```bash
python manage.py runserver
```

Сайт будет доступен по адресу: http://127.0.0.1:8000/

## 🌐 Деплой на Render.com

Проект развёрнут на бесплатном хостинге Render.com.

**Процесс деплоя:**
1. Код размещён на GitHub.
2. В Render создан **Web Service**, подключён репозиторий.
3. Настроены команды сборки:
   - Build Command: `./build.sh`
   - Start Command: `gunicorn criminology_students_book.wsgi`
4. Заданы переменные окружения:
   - `DJANGO_SECRET_KEY`
   - `DJANGO_DEBUG=False`
   - `PYTHON_VERSION`
5. Сборка и запуск выполняются автоматически при каждом пуше в `master`.
